The left group is the site's mark followed by the text block: an optional tagline, an optional credits paragraph, a copyright line, a link to /colofon/ and an optional source-code link. The right group is the engine credit (framework-credit.html), a rule, and the site's seals. The rule and the seals block are drawn only when there is at least one seal. The second and later seals are wrapped in .footer-seals-more so that, on phones, the first seal can sit beside the mark and the others stay together in a row. Deployer identity comes through site.Params and publisher.json, never a data-file override: Hugo replaces whole top-level data maps across the theme chain, so overriding footer.* in an instance data file would silently drop the sibling colofon_link_text. Params merge cleanly instead. site.Params.footer_tagline — optional sentence about the site; the paragraph is omitted when unset. publisher.json (partial publisher.html) — when it has a legal_name, the copyright line is the i18n key "footer.copyrightHolder" with {year} and {holder} (the legal name). Otherwise: site.Params.footer_copyright — optional copyright line; falls back to the i18n bundle's "footer.copyright" value ("© {year}") when unset. The {year} token is replaced at build time with `now.Format "2006"` — a single four-digit year, stable for ~12 months, so it does not churn per-page ETags materially on a given deploy. site.Params.footer_logo — optional { src, alt, href } for the site's mark. When unset or without a src, the publisher's logo_url (alt display_name or legal_name, linked to website) is used; with neither, no mark is drawn. An empty href gives a plain image. site.Params.footer_seals — optional list of { src, alt, href } (href optional). When the key is present it is used as given, and an empty list means no seals and no rule. Only an absent key falls back to the publisher's credits[] entries that have a logo_url (alt name, linked to url). site.Params.footer_credits — optional HTML prose rendered above the copyright line. When absent, no credits paragraph is rendered. site.Params.source_url — optional URL for the source-code link. When absent, the source link is omitted. Chrome strings (colophon link text, source link text) resolve from the i18n bundle selected by the manifest [ui].language setting.

{{/* Colophon page — content renderer (/colofon/) Renders the deployer-authored colophon content page (content/colofon/_index.md) inside a prose-styled article. The page is pure deployment CONTENT — credits, version, represented archives, citation examples, technology stack, accessibility, privacy, license, and contact are all institution-specific prose, authored as markdown by the deployer, NOT engine chrome. This template therefore carries no hardcoded prose of its own; it supplies the page title, the rendered .Content, the publisher block and the engine section (below). Dynamic values (version, year) come from the version/year shortcodes used in the markdown, so the content stays static-author-friendly and a version bump re-renders only this one page — the rest of the corpus stays on the diff-skip path. Prose styling: the article carries the .colofon-prose class; the base stylesheet (assets/css/base.css) defines the matching heading / body / link / list / blockquote rules (font-display headings with a bottom border, font-serif body, primary-colour underlined links, primary-colour left-border italic blockquotes) so markdown-rendered HTML matches the prior design. The engine draws no mark above the site's text; a site that wants one puts it in its Markdown. After .Content the template renders the publisher block, built from publisher.json (partial publisher.html) and repositories.json. Sections, in order: publisher, credits, represented archives, how to cite, license, privacy and data, takedown policy, contact. The block renders only when the export has a publisher.json (a site without one keeps its hand-written colophon unchanged), and each section is omitted when its fields are empty. Bilingual prose goes through lang-field.html and markdown-prose.html (Markdown, raw HTML escaped; wrapped in an element with lang when the other language is shown). The page always ends with the engine section (
): the engine's mark, a heading and a paragraph naming the engine version (hugo.Data.engine.version) with links to the engine's source and to its developers. It sits outside the publisher block, so a site without a publisher.json has it too; the mark beside the footer's credit is a link to #zasqua. The site citation template (citation_template.site) is Markdown. It is filled with {site} = site.Title, {url} = site.BaseURL, {year} = the current year and {version} = site.Params.version; other placeholders are left as written. The template is rendered by citation.html, which fills the values after rendering, so a site title with asterisks shows as written.
